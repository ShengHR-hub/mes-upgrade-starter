# MES-AI 项目 · 开发操作指导手册

> 配套文档：`需求规格说明书_定稿.md` v2、`开发启动指令.md`、`环境检查清单.md`
> 模型分工：**GPT-6.1 总控/架构/验收 ＋ DeepSeek 执行 ＋ Codex 审查**
> 核心原则：**一个模块一个新会话**，每个会话开始先喂资料，结束输出交接文档。

---

## 一、总体工作流

```
S0 总控架构（GPT-6.1，一次性）
  → 输出《接口契约说明书》
  → S1…Sn 执行会话（DeepSeek，每个模块一个新会话）
      → 每个会话结束输出《交接文档》
      → Codex 审 diff（只挑问题不重写）
  → 总控终验（GPT-6.1，按验收标准逐条过）
```

**三条铁律**
1. 执行会话不碰别的模块的代码，不改表结构——有疑问停下来问，不硬猜。
2. 密码、密钥、Token 全部走环境变量，禁止硬编码，禁止写进 git。
3. 所有演示数据必须在界面和文档里标注"演示数据"。

## 四、验收标准

### 4.1 通用验收（每个模块都适用）

- [ ] 接口与 `api-contract.md` 完全一致（路径/参数/返回/错误码）
- [ ] 本地可运行，无报错；自测命令和结果已记录
- [ ] 无硬编码密码/密钥；无 console.log 调试残留
- [ ] 演示数据处处标注"演示数据"
- [ ] 交接文档已输出到 `docs/handovers/`
- [ ] Codex 审查无"严重"问题

### 4.2 分模块验收点（对应需求文档，演示时逐条过）

**基础层**
- B1/B2：建订单 → 自动生成工单 → 工单按 JC-PLC-2001 的 10 道工序自动分解
- B3：扫码（模拟）3 步完成一次报工，工单完工数实时更新
- B4：录入一条 NG，自动生成不良品记录
- B6：输入一个 SN，展示"工序→操作员→设备→物料批次→检验"全链路
- B7：EQP-SMT-006 显示"维修中/加热区故障"；OEE 接口返回 calculationStatus: insufficient_data + 缺失项说明，不编造数字（2026-10-09 用户拍板，接受契约诚实方案）
- B8：看板数字 = 报工汇总数，能按车间/产线切换
- B9：三个角色登录看到不同菜单；审计日志有记录
- B10：至少触发 1 条预警（直通率<97% / 完成率<90% / 设备维修中）
- B11：不良 Pareto 图能渲染
- B12：选一个订单，自动算出物料缺口和采购建议

**AI 层**
- F1：5 个预设问题全对且带引用来源；超纲问题明确拒绝
  - 预设：①公司核心痛点 ②JC-PLC-2001 工序 ③EQP-SMT-006 状态 ④九大功能模块 ⑤SN 追溯解决什么问题
- F2：日报一键生成，四章节完整，数字自洽，带"演示数据"标注
- F3：4 个示例问题全对（含 1 个 7 天趋势问题），数字与演示数据一致
- F4：每条预警有原因分析 + 处置建议，建议具体可执行

### 4.3 演示前最终检查清单

- [ ] 三个服务一键启动脚本可用（或 Docker Compose）
- [ ] 近 7 天演示数据已导入，固定种子可重复
- [ ] 所有"演示数据"标注就位
- [ ] 讲解文档已按《需求规格说明书》第九节写完
- [ ] 准备一台干净电脑实测一遍（防止"在我电脑上是好的"）

## 五、会话管理与成本控制

1. **新开会话的时机**：换模块必开新会话；单个会话上下文超过约 20 万 token 开新会话；
   任务完成即开新会话，不恋战。
2. **每个新会话开头三件套**：需求文档对应章节 ＋ `api-contract.md` ＋ 上游交接文档。
   先让模型复述一遍任务，确认理解对了再动手。
3. **成本**：执行全程 DeepSeek；GPT-6.1 只用在 S0（架构）、疑难 bug、S12（终验）三个地方。
4. **交接文档存档**：`docs/handovers/`，文件名用模块英文名，如 `orders.md`。
5. **Codex 审查节奏**：每个模块执行完审一次，不要攒到最后。

## 六、问题处理手册

| 问题 | 处理 |
|------|------|
| 执行模型跑偏（做了需求之外的功能） | 叫停，让它读需求文档对应章节复述，删掉多余代码 |
| 接口与契约对不上 | 以契约为准改代码；契约本身有问题 → 升级到总控（GPT-6.1）裁决 |
| 上下文超限、模型开始胡说 | 立刻停，让当前模型输出交接文档，开新会话继续 |
| 模块间数据对不上（如日报≠看板） | 先查演示数据生成器（固定种子），再查各模块 SQL |
| 连续 30 分钟搞不定一个 bug | 停下来，把报错+相关代码发给总控，不要硬磨 |
| 想加需求文档之外的功能 | 先记到待办，不直接做；攒一批后统一找你拍板 |
