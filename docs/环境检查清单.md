# MES-AI 项目 · 开发环境检查清单

> 技术栈：Vue3（前端）+ NestJS（主后端）+ FastAPI（AI 服务）+ MySQL 8
> 检查环境：PowerShell 7（`pwsh`）

## 二、逐项检查命令（在 PowerShell 7 里一条条跑）

```powershell
# 0. 确认当前是 PowerShell 7
$PSVersionTable.PSVersion
# 期望：Major 为 7（如 7.4.x / 7.5.x）。如果是 5.1，说明还在用系统自带旧版，请用 pwsh 启动

# 1. Node.js
node -v
# 期望：v20.x.x 或 v22.x.x

# 2. npm
npm -v
# 期望：10.x.x

# 3. Python（两条都试，有一条成功即可）
python --version
py --version
# 期望：Python 3.10.x 以上（如 3.11 / 3.12）

# 4. pip
pip --version
# 期望：能输出版本号

# 5. MySQL 服务状态
Get-Service -Name MySQL* | Select-Object Name, Status
# 期望：Status 为 Running。如为 Stopped，执行：Start-Service -Name <服务名>

# 6. MySQL 客户端连通性
mysql -u root -p -e "SELECT VERSION();"
# 期望：输出 8.x 版本号（会提示输入 root 密码）

# 7. Git
git --version
# 期望：git version 2.x

# 8. Redis（可选）
redis-server --version
# 期望：能输出版本号；没有也不影响第一阶段开发

# 9. 端口占用检查（项目将用到的端口必须空闲）
@('3000','3001','8000','8080') | ForEach-Object {
  $c = Get-NetTCPConnection -LocalPort $_ -ErrorAction SilentlyContinue
  if ($c) { Write-Host "端口 $_ 被占用" -ForegroundColor Red } else { Write-Host "端口 $_ 空闲" -ForegroundColor Green }
}
# 3000=Vite前端，3001=NestJS后端，8000=FastAPI，8080=备用
```

## 四、缺失项安装指引

### Python（最可能缺的一项）
```powershell
# 方式一：winget 安装（推荐）
winget install --id Python.Python.3.12 -e
# 方式二：去 python.org 下载安装包，安装时务必勾选 "Add python.exe to PATH"
```
装完后重开 PowerShell 7，再跑 `python --version` 确认。

### MySQL 服务未启动
```powershell
Get-Service -Name MySQL* | Select-Object Name, Status  # 先看服务名
Start-Service -Name MySQL84   # 把 MySQL84 换成实际服务名
```
启动后用 `mysql -u root -p -e "SELECT VERSION();"` 验证，并**向用户确认 root 密码**（建库时需要）。

### PowerShell 7 安装/升级
```powershell
winget install --id Microsoft.PowerShell -e
```
装完后开始菜单搜 `PowerShell 7` 或命令行输入 `pwsh` 进入。注意：系统自带的 `powershell` 命令对应的是 5.1，
以后让 agent 工作时统一用 `pwsh`（PowerShell 7）。

### Redis（可选，初期可不装）
```powershell
winget install --id Redis.Redis -e
```

## 五、给 agent 的说明

1. 所有命令在 **PowerShell 7（`pwsh`）** 里执行，不要用 5.1。
2. 只做检查和安装环境，**不要**开始写项目代码，等用户下一步指令。
3. MySQL root 密码不要写在任何文件里，安装/启动后**直接问用户**要密码。
4. 检查完按第三节的格式回执，缺失项说明是否已补装成功。
